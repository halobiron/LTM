# Dữ liệu mẫu

Dữ liệu đầu vào mẫu dùng khi demo/kiểm thử thủ công (không chứa dữ liệu thật).

- `sample_users.json`: 3 tài khoản mẫu cho `POST /auth/register` (cần xác minh email trước khi đăng nhập).
- `sample_tts_sentences.json`: các câu tiếng Việt mẫu để nhập vào TTS panel.
- Giọng mẫu có sẵn: `Syltalky_API/app/tts/speakers/metadata.json`.
